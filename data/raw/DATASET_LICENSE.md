## Attribution

NOVAMART uses the publicly available synthetic retail
dataset published by atomicd on Kaggle.

The original dataset is preserved in:

`data/raw/atomicd_retail_inventory_v8.zip`

The NOVAMART project includes additional transformations,
simulated procurement records, forecasting models, inventory
recommendations, SQL analyses, and Power BI visualizations.

These additional outputs are part of the NOVAMART portfolio
project and should not be attributed to the original dataset
publisher.
